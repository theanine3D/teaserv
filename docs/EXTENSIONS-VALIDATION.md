## Causes and fixes

| Earlier failure | Evidence and correction |
| --- | --- |
| Shutdown stalls in Asio worker-pool destruction | A complete extensions-disabled control reproduced the hang. Header-order checks showed that including MinGW's `unistd.h` before Asio enabled POSIX threads, while other translation units selected Windows threads. The debugger found a POSIX thread object in Windows-thread teardown. CMake now explicitly selects POSIX threads for MinGW configurations that expose them, giving every translation unit the same Asio layout. The strict host smoke test now exits cleanly. |
| Four replay failures involving patch commands, quest loading, and legacy item randomness | With only the isolated logs changed from CRLF to LF, those four cases passed without changing packet expectations. The parser previously removed LF but left CR in command shortcuts and exact-match directives. It now removes an optional final CR. The new line-ending test replays both forms and requires explicit success for each. |
| Heart-symbol replay mismatch | This Iconv implementation maps Sega's custom byte pairs to private-use Unicode instead of reporting an untranslatable character. The custom decoder now stops before F040..F064 so its existing Sega mapping takes precedence. Ordinary multibyte characters remain intact. All 37 custom glyphs and the full heart-symbol replay pass. |

## Local Windows build environment

The tracked portable revision generator supports native Windows and paths containing spaces. Additional environment details matter when reproducing these results:

1. This GCC installation fails the default static link with duplicate `std::type_info::operator==` definitions. Final builds use `-DNEWSERV_WINDOWS_STATIC_LINK=OFF` through CMake, rather than editing generated link commands. Matching MinGW runtime DLLs and the Iconv DLL must be on `PATH`. Static linking remains the repository default and has not passed with this toolchain.
2. This checkout represents 564 Git symlinks as ordinary target-text files. `PrepareTestFixture.py` creates an isolated copy from tracked `system/` and `tests/` files, resolving link targets and copying the example checker image. It leaves the checkout unchanged and excludes ignored accounts, players, and local configuration. Final integration runs use `NEWSERV_TEST_DATA_DIR` to select that copy; source replay captures remain unchanged. A checkout with real symlinks can use the normal source directory.
3. The downloaded phosg dependency appends `b` to mode `rt`, producing `rtb`, which this Windows CRT rejects. Its ignored local `Filesystem.cc` removes `t` before appending `b`; the real library and executables were rebuilt. This dependency adjustment is not a tracked Teaserv change.

Downloaded dependencies, data fixtures, executables, and diagnostic logs remain under ignored `build/`. The Iconv import library uses the existing Git installation's DLL; no system installation or remote repository was changed. Results describe this configured local environment, not an unqualified default Windows build.

## Reproduce checks

With Lua 5.4 development headers/library installed, the independent suites need no server dependencies:

```sh
cmake -S . -B build/runtime-tests -DNEWSERV_EXTENSIONS_TESTS_ONLY=ON
cmake --build build/runtime-tests
ctest --test-dir build/runtime-tests --output-on-failure
```

Install Newserv's normal dependencies for a complete build. On this MinGW setup, also use `-DNEWSERV_WINDOWS_STATIC_LINK=OFF` and make the dependency/runtime DLLs discoverable. With a checkout containing real data symlinks:

```sh
cmake -S . -B build/server -DNEWSERV_ENABLE_EXTENSIONS=ON
cmake --build build/server
ctest --test-dir build/server -R "^(extension-|log-replays$|replay-line-endings$)" --output-on-failure
```

When Windows checked symlinks out as text, prepare a new fixture first (Python 3.9+ and local Git required):

```sh
python3 tests/extensions/PrepareTestFixture.py --source . --destination build/test-data
cmake -S . -B build/server -DNEWSERV_ENABLE_EXTENSIONS=ON -DNEWSERV_WINDOWS_STATIC_LINK=OFF -DNEWSERV_TEST_DATA_DIR=/absolute/path/to/teaserv/build/test-data
cmake --build build/server
ctest --test-dir build/server -R "^(extension-|log-replays$|replay-line-endings$)" --output-on-failure
```

The preparation script requires a new destination within this checkout's `build/`; it never deletes an existing directory. Use a different name if that destination exists. Set `--git` to the native Git executable if necessary.

`extension-host-smoke`, `extension-storage-smoke`, and `extension-package-smoke` require Python 3 and phosg's `jsonformat` executable; set `PHOSG_JSONFORMAT_EXECUTABLE` if it is not on `PATH`. The Python integration tests use bounded subprocess timeouts and remain strict about successful replay completion and shutdown. Repeat the complete build and replay checks with `NEWSERV_ENABLE_EXTENSIONS=OFF` to check the baseline mode.
